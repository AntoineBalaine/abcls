---
title: Transforms
description: Operations for modifying ABC notation
---

Transforms modify the selected elements in an ABC document. They are applied through the editor (via LSP commands) or through the CLI. Each transform operates on the current selection and returns the modified text along with updated cursor positions.

Some transforms are context-aware: they use the key signature, chord symbols, or measure accidental state from the surrounding document to produce correct results.

## Transposition and pitch

### transpose

Transposes selected notes by N semitones, respecting the key signature and measure accidentals. Context-aware.

```
Before: K:C  C D E F
After (transpose +2): K:C  D E ^F G
```

From the command line, `abcls transform` also moves the key signatures (`--keys`) and the chord symbols (`--chords`) with the notes, and `--as-new-tune` keeps the original tune and appends the transposed copy as a new tune. See the [CLI reference](/abcls/cli-reference/#transposing-a-whole-tune).

### enharmonize

Cycles through the enharmonic spellings of selected notes.

```
^F -> _G -> ^F
```

### enharmonizeToKey

Re-spells selected notes to best fit the current key signature. Context-aware.

```
K:F  ^E -> F
K:Bb _A -> _A (already fits)
```

### addSharp

Advances the accidental state of selected notes one step toward sharp. A natural note becomes sharp, a flat becomes natural, etc.

### addFlat

Advances the accidental state of selected notes one step toward flat. A natural note becomes flat, a sharp becomes natural, etc.

## Harmonization

This is an EXPERIMENTAL series of harmonization capabilities based off arranging techniques from the Berklee college. The goal is to provide some helpers to aid in arranging scores.

Expect bugs while using.

The harmonization transforms can also be run from the command line, without an editor: `abcls transform` runs any transform on a file, and `abcls harmonize` builds whole voices of block chords from the chord symbols. See the [CLI reference](/abcls/cli-reference/).

Chord symbols apply by position in time to every voice, so the chord symbols can be written in a voice of their own and the notes in another.

### harmonize

Adds a harmonizing note N diatonic steps above or below each selected note.

```
Before: K:C  C E G
After (harmonize +3): K:C  [CE] [EG] [GB]
```

### harmonizeVoicing

Builds a fully-voiced chord under a selected lead note, using the current chord symbol (or a diatonic chord derived from the key). Context-aware.

Available voicing types: `close`, `cluster`. (`spread` also exists but has no dedicated command yet.)

```
Before: "Cmaj7"C
After (close voicing): "Cmaj7"[CEGB]
```

### parallelVoicing

Shifts selected notes in parallel motion, following chord symbols. Can move diatonically, chromatically, or in a voicing-aware manner. Context-aware.

### parallelDiatonic

Shifts selected notes to match the voicing of an adjacent chord (previous or next) using diatonic intervals. Each note is moved by the diatonic distance between the current chord root and the reference chord root. Context-aware.

### parallelChromatic

Shifts selected notes to match the voicing of an adjacent chord (previous or next) using chromatic intervals. Each note is moved by the semitone distance between the current chord root and the reference chord root. Context-aware.

## Revoicing

### dropVoicing

Rearranges the notes of an already-written chord into an open voicing, lowering one or more of its inner voices by an octave. Unlike harmonization, this does not build a new chord: it acts on a chord already present in the selection, ranking its notes by sounding pitch (not by the order they're written in). Context-aware.

Available voicings: `drop2` (lowers the second-highest note), `drop24` (lowers the second and fourth-highest notes), `drop3` (lowers the third-highest note). A chord holding fewer notes than the voicing needs is left unchanged.

```
Before: [cegb]
After (drop2):  [ceGb]
After (drop24): [CeGb]
After (drop3):  [cEgb]
```

## Rhythm

### setRhythm

Sets the rhythm of selected notes and chords to a given rational duration (numerator/denominator).

```
Before: C D E F
After (setRhythm 1/4): C/4 D/4 E/4 F/4
```

### addToRhythm

Adds a rational duration to the rhythm of selected notes and chords.

### multiplyRhythm

Multiplies the duration of selected notes by a factor (default 2).

```
Before: C D E F
After (multiplyRhythm 2): C2 D2 E2 F2
```

### divideRhythm

Divides the duration of selected notes by a factor (default 2).

```
Before: C2 D2 E2 F2
After (divideRhythm 2): C D E F
```

### multiplyRhythmRebar and divideRhythmRebar

Because multiplyRhythm and divideRhythm only change the numbers, the music then no longer fits its bars: after a multiplication every bar holds two bars of music. These two transforms change the lengths and the bars together. They appear in VS Code as the commands "ABC: Double Rhythm Length and Re-bar" and "ABC: Halve Rhythm Length and Re-bar", and on the command line as the `--rebar` flag of `multiplyRhythm` and `divideRhythm`. Select whole bars before running them.

```
Before:                    C2 D2 E2 F2 | G4 A4 |
After (multiplyRhythmRebar 2): C4 D4 | E4 F4 | G8 | A8 |
```

- When multiplying, each bar that holds a selected note is cut into bars of the length of the meter. A note that crosses a new bar line is cut in two and tied (`C6 D2- | D4 E4`), a chord keeps its notes together (`[CEG]-`), and a rest is cut without a tie.
- A bar of rest written as `X` becomes as many bars of `X` as the factor says, and a chord symbol before it stays on the first one. A chord change that took half a bar (`"Gm" x4 "Dm" x4`) takes a whole bar each (`"Gm" x8 | "Dm" x8`).
- When dividing, every group of as many bars as the factor says becomes one bar, and notes that were tied across a removed bar line become one note again. Multiplying and then dividing gives back the original music.
- The factor must be a whole number of at least 2.
- Because the meter and the default note length (`M:` and `L:`) stay as they are, a cut-time copy of a tune in 4/4 also needs its `M:` line changed (to `M:C|`, which has the same bar length).

Some music cannot be re-barred, and the transform then stops with a message and changes nothing:

- A new bar line that would fall inside a tuplet, or inside a note that belongs to a broken rhythm (`A>F`).
- Bars of rest that carry different chord symbols, when dividing.
- A multi-measure rest of more than one bar (`X2`), when multiplying.

When dividing, a group of bars is left as it is if it is shorter than the factor, if it holds a repeat sign or an ending, or if it spans two lines.

## Conversion

### toRest

Converts selected notes or chords to rests of the same duration.

```
Before: C2 [CEG] D
After: z2 z D
```

### consolidateRests

Merges consecutive rests into a single rest of the combined duration.

```
Before: z z z z
After: z4
```

### legato

Extends selected notes through the rests that follow them by replacing the rests with tied copies of the preceding note. Only regular rests are targeted (multi-measure rests are left unchanged).

```
Before: C2 z2 z2
After: C2-C2-C2
```

### consolidateTiedNotes

Merges tied note sequences into single notes of the combined duration. This is the inverse of `legato`.

```
Before: C2-C2-C2
After: C6
```

### toSlashNotation

Replaces selected measures with slash notation (stemless quarter-note slashes). Context-aware.

## Structure

### remove

Removes all selected nodes from the tree.

### unwrapSingle

Unwraps single-note chords into plain notes by removing the chord brackets.

```
Before: [C] [E] [G]
After: C E G
```

### explode2, explode3, explode4

Splits chords into 2, 3, or 4 separate voice lines, distributing chord notes across the voices.

```
Before: [CEGB]
After (explode2):
V:1  [GB]
V:2  [CE]
```

### explosion

Time-aware chord explosion: distributes chord notes into separate voice lines synchronized by duration. Context-aware.

### splitSystems

Splits the system under each cursor into two systems, at the position of the cursor. In a score with several voices, every voice is split at the same musical time, and the voice markers that the new lines need are added. The cursor goes to the start of the new system. Context-aware.

### joinSystems

Joins the system under each cursor with the system that follows it. It is the inverse of `splitSystems`: each voice line of the next system is appended to the line of the same voice, and the voice marker that the split had added is dropped. Lines such as `P:` or `%%text` are kept. Nothing happens when the cursor is in the last system. The cursor goes to the first note that was appended.

In Visual Studio Code, the command is "ABC: Join System with Next".

### interleaveVoices

Takes a tune whose voices are written one after the other, in deferred mode, and rewrites it as systems that hold all the voices: every voice is cut every N bars, and the n-th pieces of all the voices make the n-th system, one line per voice, in the order in which the voices first appear. Because the cuts are made at bar numbers and not at the lines of the source, the lines of a system have the same number of bars. A voice that has fewer bars stops appearing in the last systems.

```
Before (N = 2):
V:1
C | D | E | F |
V:2
c | d | e | f |

After:
[V:1] C | D |
[V:2] c | d |
[V:1] E | F |
[V:2] e | f |
```

Run the formatter afterwards to align the bars of the voices. The empty `%` comment lines that separated systems are dropped, because the formatter writes its own. A tune is left as it is when it has fewer than two voices, is in linear mode, or has lines of lyrics (`w:`). The bars are matched by their number, so the voices must start together.

In Visual Studio Code, the command is "ABC: Interleave Voices", and it asks for the number of bars per system.

## Voice

### addVoice

Inserts a new `V:` voice declaration into the tune header.

### insertVoiceLine

Duplicates lines containing selected notes into a new voice. Non-selected notes are replaced with rests.

### voiceInfoLineToInline

Converts `V:` info-line voice markers to inline `[V:...]` form.

```
Before:
V:1
C D E F

After:
[V:1] C D E F
```

### voiceInlineToInfoLine

Converts `[V:...]` inline voice markers to `V:` info-line form. The inverse of `voiceInfoLineToInline`.
