description: Select and transform ABC notation with a menu of keys in VS Code

The VS Code extension has two key menus, one to select musical elements and one to transform them. They work like the user modes of the [Kakoune plugin](/user-guide/kakoune/): you press a key to open a menu, then a key to run a command. The menu stays open, so the next key runs another command, until you press `Esc`. Some keys open a smaller menu of their own, and a number typed before a transform is its count.

The keys are not the same as those of the Kakoune plugin. The tables further down list every key of both menus.

## Opening a menu

With the VSCodeVim extension, `k` opens the select menu and `h` opens the transform menu in the Normal, Visual and Visual Line modes of an ABC file, when no menu is open yet. Both keys replace the Vim motions of the same name, and the VSCodeVim modes are the only place where they open a menu by default. Without VSCodeVim there is no default key, because `h` and `k` would stop typing in every ABC file.

The two keys are the keybindings of the commands `abc.menu.select` and `abc.menu.transform`, so you change them in `keybindings.json` like any other key:

```json
[
  { "key": "space s", "command": "abc.menu.select", "when": "editorLangId == abc && editorTextFocus && !abc.modeMenuOpen && vim.mode == 'Normal'" },
  { "key": "space t", "command": "abc.menu.transform", "when": "editorLangId == abc && editorTextFocus && !abc.modeMenuOpen && vim.mode == 'Normal'" }
]
```

## Using a menu

While a menu is open, every key goes to it. These keys switch menus, close a menu, or edit the count:

| Key         | What it does                                                                 |
| ----------- | ---------------------------------------------------------------------------- |
| `Tab`       | Switch to the other menu (written `<tab>` in the tables)                     |
| `h`         | In the select menu, go to the transform menu                                 |
| `k`         | In the transform menu, go to the select menu                                 |
| `Backspace` | Remove the last digit of the count, or go back from a smaller menu, or close |
| `Esc`       | Close the menu                                                               |

Both menus take a count of up to three digits, and a leading zero is ignored. Type it before the command: `5 g c` in the transform menu is a close voicing with five voices, and the count of a voicing is its number of voices, 4, 5 or 6. In the select menu, `3 >` moves to the third note after the selection and `3 <` to the third note before it, stopping at the last note that exists. A digit that is itself bound in a menu is a command, not a count, so inside the `g` menu of the transform menu the digits `2`, `3` and `4` choose a drop voicing, and a count can only be typed before `g`. In the select menu, the digits `1` to `9` of the `f` menu select the note that many places from the top, and `t` is the same as `f 1`.

A key written as `<a-t>` is Alt plus `t`, `<c-up>` is Ctrl plus the up arrow, and `<c-S-up>` is Ctrl plus Shift plus the up arrow. An uppercase letter is typed with Shift.

A transform acts on the current selection, so use the select menu first to choose what the transform applies to.

## The key view

The view of the keys opens below the editor each time a menu opens, without taking the keyboard focus. When the editor area has one group, it is split in two rows for the view, and the view is as wide as the window. It shows the keys of the current menu, grouped by category, and a click on a key presses it. It also draws a keyboard.

Because VS Code gives an extension no event for a held Shift or Alt key, the keyboard cannot follow the modifiers. Every key is drawn with its four layers at once: Shift at the top left, AltGr and Shift at the top right, the plain key at the bottom left and AltGr at the bottom right. A cell with a binding has the colour of its category and the short name of its command, and hovering a key shows the full detail of its four layers. The keys that no key of the keyboard carries, such as the Ctrl arrows, are in a row above it.

On a Mac, AltGr is the Option key. The keyboard shows an AltGr layer as the symbol that the key types when that symbol is bound, as the `<` of the BÉPO layout is, and otherwise as the Alt chord of the key, such as `<a-t>`.

| Setting                 | Values                     | What it does                                                                                                                                                                              |
| ----------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `abc.menu.sticky`       | `true`, `false`            | Keeps the menu open after a command. With `false`, a command closes the menu, like a user mode of the Kakoune plugin. The default is `true`.                                              |
| `abc.menuView.autoOpen` | `true`, `false`            | Opens the view each time a menu opens. The default is `true`.                                                                                                                             |
| `abc.menuView.location` | `below`, `beside`, `panel` | Puts the view in a row below the editor, which is the default, in a column beside it, or in the bottom panel. In the bottom panel it does not open by itself: open the tab ABC keys once. |
| `abc.keyboardLayout`    | `qwerty`, `bepo`           | The layout that the keyboard draws. The extension does not detect it.                                                                                                                     |
| `abc.keyboardGeometry`  | `staggered`, `ortholinear` | Whether the rows are shifted against each other, or the keys are in aligned columns.                                                                                                      |
| `abc.keyboardIsoKeys`   | `true`, `false`            | Draws the keys that only ISO keyboards have.                                                                                                                                              |

The settings of the view and of the keyboard belong to the user, and a workspace cannot set them. The setting `abc.keymap` can also be set for a workspace.

The commands `ABC: Show the menu view` and `ABC: Hide the menu view` open and close the view by hand.

## Changing the keys

The setting `abc.keymap` changes the keys of the menus without changing the extension. It is an object with the keys `select` and `transform`. Each holds an object that maps a key to a binding that is merged into the default one, or to `null` to remove it.

Move the command that rests on `s` in the transform menu to `S`, and remove the command of `j`:

```json
{
  "abc.keymap": {
    "transform": {
      "S": { "label": "split system", "category": "layout", "action": { "kind": "command", "name": "abc.splitSystem" } },
      "s": null,
      "j": null
    }
  }
}
```

Change only the label of a key and keep its action:

```json
{
  "abc.keymap": {
    "select": { "c": { "label": "every chord" } }
  }
}
```

Add a drop 2 voicing to the main transform menu:

```json
{
  "abc.keymap": {
    "transform": {
      "d": { "label": "drop 2", "category": "voicing", "action": { "kind": "transform", "name": "dropVoicing", "args": ["drop2"] } }
    }
  }
}
```

A binding has a `label`, a `category`, and an `action` with a `kind` (`selector`, `transform` or `command`), a `name`, and optional `args`. An argument can be `{ "count": { "default": 4, "multiplier": 1 } }`, which stands for the number typed in the menu, or the default when no number was typed, times the multiplier. With a default of 1 and a multiplier of 12, as the octave keys have, no count gives 12 and a count of 2 gives 24. A binding that has `children` instead of an `action` is a smaller menu. The setting reports its problems in a message when it is invalid.

### Keys that have no keybinding

While a menu is open, the extension routes the letters, digits, ASCII symbols, the Alt chords of the letters and the Ctrl arrows to the menu. A key that is not among them, such as an accented letter, needs a keybinding of your own. The extension tells you so with the entry to add, and you write the key of your keyboard in it, for example:

```json
{ "key": "ctrl+alt+e", "command": "abc.menu.key", "args": { "notation": "<c-a-e>" }, "when": "abc.modeMenuOpen && editorTextFocus && editorLangId == abc" }
```

### The number of voices of a voicing

The commands `abc.harmonizeClose`, `abc.harmonizeCluster` and `abc.harmonizeSpread` take the number of voices, 4, 5 or 6, as an argument, so a keybinding can ask for five voices:

```json
{ "key": "ctrl+alt+5", "command": "abc.harmonizeClose", "args": { "voices": 5 } }
```

Any other value shows the message "Voice count must be 4, 5 or 6".

## Limits

- The AltGr layers of the keyboard come from the macOS layouts `U.S.` and `bépo 1.1`. On Windows and Linux AltGr is Ctrl and Alt together, and other layouts have other AltGr symbols, so the Alt chords and the AltGr symbols may collide there.
- A keybinding that stands for a shifted symbol, such as `{`, is written with the key of a US keyboard, and VS Code matches it through the layout. On another layout such a key, or a digit that needs Shift, may not reach the menu, and a keybinding of your own fixes it.
- The panel cannot show which modifier is held, because VS Code gives extensions no event for it.
